Politique de Confidentialité - MCP TikTok Server

Dernière mise à jour : Janvier 2025

Introduction

Cette politique de confidentialité décrit comment le serveur MCP TikTok ("l'Application") traite vos données personnelles lorsque vous l'utilisez pour accéder à votre compte TikTok.

Collecte de Données

Données Collectées

L'Application collecte et traite les données suivantes de votre compte TikTok via l'API officielle TikTok :

  • Informations de profil : Nom d'affichage, avatar, bio, statut de vérification
  • Statistiques de compte : Nombre d'abonnés, d'abonnements, de likes, de vidéos
  • Données de vidéos : Liste de vos vidéos, titres, descriptions, statistiques (vues, likes, commentaires, partages)
  • Tokens d'authentification : Access tokens et refresh tokens pour l'authentification OAuth 2.0

Comment les Données sont Collectées

Les données sont collectées uniquement via l'API officielle TikTok lorsque vous :

  1. Vous authentifiez avec votre compte TikTok via OAuth 2.0
  2. Utilisez les outils MCP pour récupérer vos données

Stockage des Données

Local uniquement

Toutes les données sont stockées localement sur votre ordinateur uniquement.

  • Les tokens d'authentification sont stockés dans les variables d'environnement de votre configuration MCP
  • Aucune donnée n'est transmise à des serveurs externes
  • Aucune donnée n'est stockée dans des bases de données cloud
  • Aucune donnée n'est partagée avec des tiers

Sécurité

  • Les tokens sont stockés de manière sécurisée dans votre configuration locale
  • Il est de votre responsabilité de protéger votre fichier de configuration MCP
  • Nous recommandons de ne jamais commiter vos tokens dans des dépôts Git publics

Utilisation des Données

Les données collectées sont utilisées uniquement pour :

  • Afficher vos informations de profil TikTok
  • Lister vos vidéos et leurs statistiques
  • Fournir des analyses de performance de vos vidéos
  • Permettre l'intégration avec des assistants IA compatibles MCP

Aucune donnée n'est utilisée pour :

  • La publicité
  • Le marketing
  • La revente à des tiers
  • L'analyse comportementale

Partage des Données

Nous ne partageons aucune donnée avec des tiers.

L'Application fonctionne entièrement en local et ne transmet aucune donnée à des serveurs externes, sauf pour les requêtes directes à l'API TikTok officielle nécessaires au fonctionnement de l'application.

API TikTok

Cette application utilise l'API officielle TikTok. Pour plus d'informations sur la façon dont TikTok traite vos données, consultez la Politique de Confidentialité de TikTok.

Vos Droits

Conformément aux réglementations sur la protection des données (RGPD, CCPA, etc.), vous avez le droit de :

  • Accéder à vos données : Vous pouvez voir toutes les données collectées via les outils MCP
  • Supprimer vos données : Supprimez simplement les tokens de votre configuration MCP
  • Révoquer l'accès : Révoquez l'autorisation de l'application dans les paramètres de votre compte TikTok

Cookies et Technologies Similaires

Cette application n'utilise pas de cookies ou de technologies de suivi similaires.

Modifications de cette Politique

Nous nous réservons le droit de modifier cette politique de confidentialité à tout moment. Les modifications seront publiées sur cette page avec une date de mise à jour.

Contact

Pour toute question concernant cette politique de confidentialité, veuillez ouvrir une issue sur le dépôt GitHub du projet.

Consentement

En utilisant cette application, vous consentez à cette politique de confidentialité.
